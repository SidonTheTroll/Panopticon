### 5. Answer the following questions in short. 
1. How many interrupt lines are found in 8085 microprocessor?
   - The 8085 microprocessor has five hardware interrupt lines. These include TRAP, RST7.5, RST6.5, RST5.5, and INTR.

2. Name one 8-bit register of 8085 microprocessor.
   - One example of an 8-bit register in the 8085 microprocessor is the Accumulator (A). It is widely used for arithmetic and logic operations.

3. What is the size of data bus for 8085 microprocessor?
   - The 8085 microprocessor uses an 8-bit data bus. This allows it to transfer 8 bits of data in parallel at a time.

4. Which instruction is used to complement the content of the accumulator?
   - The instruction used to complement the accumulator is **CMA**. It inverts all the bits of the accumulator (i.e., performs one’s complement).

5. How many T-states does an opcode fetch cycle take?
   - An opcode fetch cycle in the 8085 typically takes **4 T-states**. This is the time required by the processor to fetch and decode the instruction.
